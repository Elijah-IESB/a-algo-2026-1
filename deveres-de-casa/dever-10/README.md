# Dever 10

Aplicacao do algoritmo KNN no dataset Breast Cancer Wisconsin.

Arquivos:

- `knn_breast_cancer.py`: script Python da atividade.
- `respostas.txt`: comparacao dos resultados e respostas das perguntas.
- `knn_breast_cancer.ipynb`: notebook com a mesma solucao.
- `requirements.txt`: dependencia necessaria para executar.

Para executar:

```bash
pip install -r requirements.txt
python knn_breast_cancer.py
```
